| Fichier | Contenu | Usage prévu |
|---|---|---|
| `celer-it-logo.jpg` | Logo Celer-IT (carte, 696 × 551 px, JPEG sans transparence) | En-tête de l'application (phase 3) ; en-tête des devis PDF et XLSX (phase 5) |
| `evolis-platinum-reseller-2026-2027.jpg` | Badge « Evolis Platinum Reseller 2026/2027 » de Celer-IT (1535 × 1535 px) | Pied des devis clients, désactivable (phase 5) |

Fournis par l'utilisateur, utilisés tels quels.

- **Thème sombre** : les deux JPEG ont un fond blanc. On les affiche sur une pastille claire. Une version SVG ou PNG transparente du logo, si elle existe, pourra remplacer l'image sans changer le code.
- **Badge** : il porte une période de validité (2026/2027). La date de fin se saisit dans les paramètres, jamais devinée ; elle sert à rappeler le renouvellement.
- **Coordonnées de la société** (raison sociale, adresse, SIRET, contact) : saisies dans les paramètres de l'application, jamais inventées.
